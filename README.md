## 快速启动 STBL Layer1 区块链验证者节点

### 1. 克隆仓库

```bash
git clone https://github.com/STBLFoundation/STBL-Layer1.git
cd STBL-Layer1
```

### 2. 安装依赖
```bash
go mod tidy
```
### 3. 编译项目
```bash
make build
```

编译完成后，将在当前目录生成 stbl 可执行文件，您已准备好启动区块链节点！
